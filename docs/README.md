## How to use this guide

- **Read chapter 1 first** (it's short), then skip anywhere you like.
- **Nothing here is a subscription trap.** Every tool recommended in chapter 2 is free at the level you need to start.
- **No account cull, bold purge, or "do a 30-day challenge."** The triage habit in chapter 5 is designed for low-energy days.
- **No tracking, ever.** The static site built from these docs has no analytics, no cookies, no scripts calling home. What you read is your business.
